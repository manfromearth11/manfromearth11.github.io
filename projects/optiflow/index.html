01 / THE CHALLENGE

Expressiveness and speed

Offline reinforcement learning learns from a fixed dataset. For a given state, several distinct actions may lead to high return. The goal is to retain these high-value modes while avoiding low-value or unsupported actions.

Gaussian policies are fast, but unimodal. Multi-step flow policies can represent complex action distributions, but require repeated computation. Distilling them into one step can collapse distinct modes; directly maximizing the critic can pull actions outside the data support.

Can we learn an expressive one-step policy?

02 / OUR APPROACH

Learn the policy through sample allocation

OptiFlow improves a one-step policy by selecting among actions proposed by a behavior-cloned reference flow policy. Instead of moving actions uphill through the critic, it allocates more supervision to high-value reference candidates. Value determines how much mass a candidate receives; geometry determines the pairings.

  1. Propose and score

    A multi-step reference policy learns from dataset actions through value-aware behavior cloning. The critic scores its candidate actions.

  2. Allocate with transport

    Higher-value candidates receive more target mass. Entropic OT matches one-step samples to these candidates using action distance.

  3. Distill into one step

    Each sample learns from its maximum-mass partner. The targets and transport plan are fixed during the update; there is no direct critic maximization of the one-step policy.

Improve within the reference policy’s action support

The candidate actions come from behavior cloning. The reference flow is trained on dataset actions with value-aware behavior cloning (VaBC): it gives greater weight to high-value dataset actions while learning their multimodal distribution. It therefore provides an in-distribution proposal mechanism for policy improvement.

The critic scores these reference candidates to set their transport weights. The one-step policy then regresses toward selected candidates, with no direct critic-maximization term. This anchors its supervision to behavior-supported actions and avoids searching for targets in unsupported regions where the critic may overestimate value.

This describes the transport target-selection mechanism, rather than a hard support guarantee for every generated action. Critic learning and VaBC weighting also evaluate one-step-policy actions.

Why optimal transport?

Suppose two target modes have equal value, but the initial samples lie closer to one of them. If every sample chooses a target independently, their assignments can concentrate on a single mode. OT constrains the total mass each target receives, so the assignment accounts for the whole distribution.

Value sets the mass; geometry sets the match

OT moves probability mass from one-step samples to reference candidates. Its row constraints fix how much mass each source sends, and its column constraints fix how much each candidate receives. Entropic regularization smooths the plan; Sinkhorn alternately rescales its rows and columns to satisfy these constraints.

Value belongs in the reference-side marginal. With a fixed target marginal, adding a candidate-only value term to the transport cost cannot change the total mass assigned to that candidate. OptiFlow instead gives higher-value candidates more target mass, then uses action distance to find compatible pairings. This separates which actions to favor from how to match them.

The transport objective

One-step samples have uniform mass, while reference candidates receive a softmax weight from the critic:

p_i=\frac{1}{N},\qquad q_j=\frac{\exp(Q_\phi(s,\tilde a_j)/\tau)}{\sum_k\exp(Q_\phi(s,\tilde a_k)/\tau)}

The cost uses squared action distance, normalized per state. Sinkhorn computes the entropy-regularized plan:

P^*=\underset{P\in\Pi(p,q)}{\arg\min}\;\langle P,C\rangle+\varepsilon\sum_{i,j}P_{ij}(\log P_{ij}-1)

For each row, select its maximum-mass target and regress the one-step output toward it, weighted by the selected transport mass. The main configuration uses 16 one-step samples, 64 reference candidates, and 30 Sinkhorn iterations during training. See Section 4 and Appendix D for the complete objectives and implementation.

03 / CONTROLLED EXPERIMENTS

Does the policy keep multiple good modes?

Two-mode bandit

Two high-value modes are separated by a suboptimal region. Strong distillation can pull samples toward that region; weak distillation can let critic maximization push them outside behavior support. OptiFlow captures both high-value modes in this diagnostic.

Paper Figure 2. Each dot is a sampled action, not a trajectory; the curve indicates behavior support. Select any panel to enlarge.

Four equally optimal goals

The four goals are equally optimal, but unevenly represented in the dataset. FQL trades off diversity and quality as its distillation strength changes: stronger distillation improves mode coverage but reduces return. OptiFlow-BC achieves balanced coverage of all four goals with the highest return in this experiment.

What is OptiFlow-BC?

OptiFlow-BC = a standard BC reference + value-weighted OT distillation. It replaces the full method’s value-aware BC reference with ordinary flow behavior cloning, while keeping the same value-weighted transport coupling and one-step distillation. “BC” describes how the reference is trained; the one-step policy still uses critic-weighted transport.

This controlled variant isolates the contribution of distillation from improvements to the reference policy. Full OptiFlow combines both: a VaBC reference and OT distillation.

What does transport contribute?

On the same 10-task OGBench ablation suite, FQL and OptiFlow-BC use the same standard BC reference setup. Changing the distillation mechanism raises average one-step success from 37.6% to 48.6%. Adding the value-aware reference in full OptiFlow raises it further to 57.3%. Better target allocation and better candidate proposals contribute separately.
