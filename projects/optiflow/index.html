01 / THE CHALLENGE

Expressiveness and speed

Offline reinforcement learning learns from a fixed dataset. For a given state, several distinct actions may lead to high return. The goal is to retain these high-value modes while avoiding low-value or unsupported actions.

Gaussian policies are fast, but unimodal. Multi-step flow policies can represent complex action distributions, but require repeated computation. Distilling them into one step can collapse distinct modes; directly maximizing the critic can pull actions outside the data support.

Can we learn an expressive one-step policy?

02 / OUR APPROACH

Learn the policy through sample allocation

OptiFlow improves a one-step policy by selecting among actions proposed by a reference flow policy. Instead of moving actions uphill through the critic, it allocates more supervision to high-value reference candidates. Value determines how much mass a candidate receives; geometry determines the pairings.

The reference policy learns from dataset actions and supplies behavior-supported candidates. Value-weighted OT assigns more mass to better candidates while preserving their distinct modes. We distill these assignments into a one-step policy, so the extra computation stays in training.

03 / ALGORITHM

Algorithm

Click to see the full algorithm

Algorithm 1 OptiFlow training

  1. for each training iteration do
  2. Sample a minibatch B = {(s, a, r, s′)} from D
  3. Update critic Qφ using ∇φ LQ
  4. Update reference policy μω using ∇ω Lref
  5. for each state s in B do
  6. Sample N one-step actions ai = μθ(s, zi)
  7. Sample M reference actions ãj = μω(s, z̃j)
  8. Set pi = 1/N and qj = softmaxj(Qφ(s, ãj)/τ)
  9. Construct Cij from squared action distances, normalized per state
  10. Compute P* = Sinkhorn(C, p, q, ε, T)
  11. Select j*i = argmaxj P*ij
  12. end for
  13. Update one-step policy μθ using ∇θ Ldistill
  14. Update target critic Qφ̄
  15. end for

Output: one-step policy μθ

Algorithm 1 of the paper. Reference targets and transport assignments are held fixed during distillation.

  • OptiFlow has three components: a critic Qφ, a reference flow policy μω, and a one-step policy μθ.
  • The critic is trained with the standard Bellman loss.
  • The reference policy is trained with value-aware behavior cloning (VaBC):
    \mathcal L_{\mathrm{ref}}(\omega)=\mathbb E\left[\underbrace{g_\eta(s,a)}_{\text{Value weight}}\underbrace{\left\|v_\omega(s,a_t,t)-(a-\epsilon)\right\|_2^2}_{\text{Flow-matching loss}}\right]
    Here, a is a dataset action, ε is Gaussian noise, and at = (1 − t)ε + ta. The weight gη favors higher-value dataset actions. Setting gη = 1 gives standard BC and yields OptiFlow-BC.
  • The one-step policy learns from reference actions assigned by value-weighted optimal transport:
    \mathcal L_{\mathrm{distill}}(\theta)=\mathbb E\left[\sum_i\underbrace{P^*_{i,j_i^*}}_{\text{Transport weight}}\underbrace{\left\|\mu_\theta(s,z_i)-\tilde a_{j_i^*}\right\|_2^2}_{\text{Distillation loss}}\right],\qquad j_i^*\in\arg\max_jP^*_{ij}
    P* is the value-weighted OT plan, and ã is a reference action. The plan and targets are fixed during the update; there is no direct critic maximization. This distillation is the same in OptiFlow and OptiFlow-BC.
  • The output is the one-step policy: a single forward pass at inference.

04 / CONTROLLED EXPERIMENTS

Does the policy keep multiple good modes?

Two-mode bandit

Two high-value modes are separated by a suboptimal region. Strong distillation can pull samples toward that region; weak distillation can let critic maximization push them outside behavior support. OptiFlow captures both high-value modes in this diagnostic.

Paper Figure 2. Each dot is a sampled action, not a trajectory; the curve indicates behavior support. Select any panel to enlarge.

Four equally optimal goals

The four goals are equally optimal, but unevenly represented in the dataset. FQL trades off diversity and quality as its distillation strength changes: stronger distillation improves mode coverage but reduces return. OptiFlow-BC achieves balanced coverage of all four goals with the highest return in this experiment.

Here we use OptiFlow-BC, with a standard BC-trained reference policy, to isolate the effect of OT distillation from value-aware reference learning.

Performance across navigation and manipulation

What does transport contribute?

On the same 10-task OGBench ablation suite, FQL and OptiFlow-BC use the same standard BC reference setup. Changing the distillation mechanism raises average one-step success from 37.6% to 48.6%. Adding the value-aware reference in full OptiFlow raises it further to 57.3%. Better target allocation and better candidate proposals contribute separately.
